# Site AMI Avocats

Site vitrine du cabinet AMI Avocats — page unique en HTML/React (Babel dans le navigateur), plus trois pages légales statiques.

## Contenu

- `index.html` — le site (accueil, expertises, équipe, actualités, contact)
- `mentions-legales.html`, `politique-de-confidentialite.html`, `gestion-des-cookies.html` — pages légales
- `legal.css` — feuille de style des pages légales
- `assets/` — portraits et visuels optimisés pour le web
- `sitemap.xml`, `robots.txt` — référencement

## Mise en ligne (GitHub Pages)

1. Déposer le contenu de ce dossier à la racine du dépôt.
2. Dans *Settings → Pages*, choisir la branche `main` et le dossier `/ (root)`.
3. Le site est publié quelques minutes plus tard.

## Vidéo d'arrière-plan

La vidéo du hero est chargée depuis `https://shawarmix.github.io/ami-avocats-site/assets/`. Si le dépôt change de nom, mettre à jour la constante `BASE` dans `index.html`.
